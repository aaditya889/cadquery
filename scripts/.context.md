> [!IMPORTANT]
> **cq-server `show_object()` BUG**: NEVER pass a `cq.Assembly` to `show_object()`.
> `ui.assembly.add(assembly, color=…)` re-wraps the Assembly with a flat color, corrupting
> the internal tessellation metadata → "An error occurred when tessellating the assembly."
>
> **Correct pattern — pass each solid individually:**
> ```python
> show_object(body_a, options={"color": (0.85, 0.85, 0.85)})
> show_object(body_b, options={"color": (0.8, 0.1, 0.1)})
> ```
> `cq.Assembly` is still fine for `.export()` / `exporters.export()`.


## Soldering Station — Current State (v1.0)

### Physical Measurements (user-provided)
- Hot air gun diameter: **2.5cm** (inner_dia=27mm with clearance)
- Solder cleaning mesh holder: **6.5cm** diameter
- Soldering iron barrel: **~22mm** inner

### Layout (290×280mm mat, origin at center)
All components arranged in 4 columns along the back edge, workspace pocket in front:

```
  Col 1 (X≈-125)  │ Col 2 (X≈-83)  │  Col 3 (X≈-13.5)  │ Col 4 (X≈68.5) + Tray2 (X≈124)
  ─────────────────┼─────────────────┼────────────────────┼──────────────────────────────────
  Tray1 (4×1)      │ Hot Air Holder  │ Box3 (large)       │ Iron Holder (75×108 base)
                   │ Box2 (small)    │ Tool Holder        │   - 65mm sponge cup
                   │ Box1 (medium)   │ PCB Holder (slots) │   - spool peg
                   │                 │                    │   - tilted 35° iron sleeve
                   │                 │                    │ Tray2 (to the right, Y=70)
                   │                 │                    │ Sponge pocket (below Tray2)
  ─────────────────┴─────────────────┴────────────────────┴──────────────────────────────────
                              Workspace Pocket (278×145, 1.2mm deep)
```

### Key Coordinates (computed, not hardcoded)
- `margin=6, gap=3, back_y_edge=134, left_x_edge=-139`
- Each column's left edge = previous column's right edge + gap
- `col2_left = left_x_edge + tray1_outer_l + gap`
- `col3_left = col2_left + hot_air_size + gap`
- `col4_left = col3_left + box3_outer_l + gap`
- Tray2 at `Y=70` (below tilted cylinder at Y≈117) to avoid 3D intersection
- Pocket centered at `(0, -65.5)`, top Y=14 (3mm below box1 bottom at Y=17)

### Wall Thickness
All walls = **2.0mm** (2 perimeters with 1mm nozzle). Applies to: tray_wall, box1/2/3_wall.

### Component Library Details

**create_safety_iron_holder** — Most complex component:
- Base plate + tilted cylinder (tilt_angle° from vertical around Y-axis)
- Sponge cup (sponge_diameter, sponge_depth) positioned at bottom of base
- Spool peg (spool_peg_height, spool_peg_radius) at top-left corner
- Default base_length = `max(outer_dia, sponge_dia) + 10`
- Default base_width = `outer_dia + sponge_dia + 15`
- **Flat sponge tray DISABLED** (threshold set to 999) — overlaps 65mm cup geometry

**create_hot_air_holder** — Tilted sleeve on square base:
- `inner_diameter`, `outer_diameter`, `length`, `tilt_angle` (25° default)
- `base_size` (50mm square), `base_thickness`

**create_consolidated_tool_holder** — Multi-hole block:
- Holes for: desoldering pump, flux pen, tweezers (rectangular), soldering tips
- Block dims: 85×38mm

**create_lidded_box** → returns dict with `box`, `lid`, `outer_length`, `outer_width`, `lid_offset_z`

### Intersection Avoidance Rules (LEARNED THE HARD WAY)
1. The tilted iron sleeve extends **~43mm** beyond the base in +X at full height: `sin(35°)*50 + 14 = 42.7mm`
2. Tray2 must be at different Y than the tilted cylinder (Y≈117 world) to avoid 3D overlap
3. The 65mm sponge cup (radius 34.5mm) dominates the iron holder base — no room for additional features on it
4. Always verify bounding box after compilation: `X: [-145, 145], Y: [-140, 140]`
5. Hot air sleeve tilts backward in +Y, extending ~3mm past mat back edge (acceptable)

## Sink Caddy — `home_utilities/sink_caddy.py`

Hook-over-sink-rim design with 3 compartments and drainage holes.

### Key Parameters (at top of file)
| Parameter | Default | Description |
|-----------|---------|-------------|
| sink_rim_thickness | 8mm | Thickness of sink rim — **USER MUST MEASURE** |
| hook_clearance | 1.5mm | Gap around rim |
| hook_drop | 25mm | Inner arm depth |
| caddy_length | 200mm | Total width |
| caddy_depth | 80mm | Front-to-back |
| caddy_height | 100mm | Wall height |
| sponge_width | 82mm | 1st compartment |
| brush_width | 52mm | 2nd compartment |
| soap_width | auto | 3rd compartment (remaining space) |
| drain_dia / drain_spacing | 5 / 12mm | Drainage hole pattern |

### Design Notes
- Hook is built as a 2D profile in the YZ plane, extruded along X
- The hook channel is open at the bottom — caddy slides DOWN onto the rim
- 3 compartments divided by internal walls; soap width auto-calculated
- Grid of drainage holes in each compartment floor
- `wall = 2.0mm` for 1mm nozzle

## Bag Clips + Rack — `home_utilities/bag_clips.py`

### Clip Design
U-channel slide-on clip with:
- **Entry bumps**: Small triangular wedges near the opening that narrow the entrance by `entry_bump` mm. Creates snap-in retention.
- **Grip ridges**: Raised lines on inner jaw surfaces for friction.
- **Label tab**: Extension at spine end for finger grip.

### Key Parameters
| Parameter | Default | Description |
|-----------|---------|-------------|
| clip_width | 80mm | Width across bag |
| clip_depth | 25mm | How deep the bag slides in |
| jaw_gap | 7mm | Gap between jaws (fits bags up to ~6mm) |
| jaw_thickness | 2mm | Each jaw wall |
| entry_bump | 1mm | Snap-in bump height |
| num_clips | 6 | Slots on the rack |

### Rack Design
Wall-mounted bar with vertical slots. Clips drop in from the top. Countersunk screw holes at both ends.

## Desk Organizer — `home_utilities/desk_organizer.py`

Hanging organizer basket designed for power strips/cables with desk-edge clamping.

### Key Parameters
| Parameter | Default | Description |
|-----------|---------|-------------|
| basket_length | 220mm | Inner width (X) |
| basket_width | 160mm | Inner depth (Y) |
| basket_height | 75mm | Inner height (Z) |
| desk_thickness_max | 38mm | Max desk top thickness |
| clearance_above_desk | 40mm | Vertical drop to basket |
| bracket_width | 25mm | Width of hanger arm |
| bracket_thickness | 8mm | Arm profile thickness |

### Design Notes
- **Grid walls & bottom**: Composed of intersecting 3mm horizontal/vertical square rods. Matches look of a metal mesh basket while using minimal filament and printing clean.
- **T-slot connection**: 2 vertical sliding tracks on the back wall of the basket. The brackets slide in from the top and rest against a bottom stopper block.
- **No-screw C-clamp**: Brackets hook over the table edge. They feature a sloped bottom jaw.
- **Locking wedges**: Two wedges (thin: 12mm, thick: 20mm) with grip ridges are provided. You slide them into the bottom jaw gap to clamp the organizer securely onto tables between 15mm and 38mm thick.

## General Design Rules
1. **Clearance**: Always add 1-2mm clearance when a tool/object needs to fit INTO a holder. The `sponge_diameter` parameter should be tool_diameter + 2mm.
2. **Wall thickness**: Must be a multiple of nozzle diameter. Currently all walls = 2.0mm (2 perimeters × 1mm nozzle).
3. **Parameters at the top**: Every `.py` file has all user-facing measurements in the first ~40 lines, with `COMPUTED` section below. Changing a parameter should NOT corrupt geometry.
4. **Export**: STLs go to `export/` directory. Use `exporters.export(body, "export/filename.stl")`.
